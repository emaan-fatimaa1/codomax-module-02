# Linux CLI – Introduction

## 1. What is CLI?

CLI stands for Command Line Interface. It allows users to interact with the operating system by entering text-based commands in a terminal.

## 2. Importance of CLI in DevOps

CLI is important in DevOps because Linux servers are commonly managed through command-line interfaces. It helps administrators manage files, users, processes, services, and servers.

## 3. Basic Linux Commands

| Command | Description |
|---|---|
| pwd | Displays the current working directory. |
| ls | Lists files and directories. |
| cd | Changes the current directory. |
| whoami | Displays the current logged-in username. |
| hostname | Displays the system hostname. |
| date | Displays the current date and time. |
| uname -a | Displays Linux system and kernel information. |
| df -h | Displays disk space usage. |
| free -h | Displays memory usage. |
| ls -la | Lists all files, including hidden files, with detailed information. |

## 4. Practical Implementation

The above commands were executed in the Ubuntu terminal to explore Linux CLI operations and system information.
